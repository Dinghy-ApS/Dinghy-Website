# Dinghy Website

Statisk marketing-site for Dinghy bygget i HTML, CSS og en smule vanilla JavaScript.

## Struktur

- `index.html`: Forside
- `ideen.html`: Produktvision og koncept
- `services.html`: Oversigt over services
- `om-os.html`: Team og baggrund
- `kontakt.html`: Kontaktoplysninger
- `faq.html`: Ofte stillede spørgsmål
- `privacy.html`, `terms.html`, `juridisk.html`: Juridiske sider
- `global.css`: Fælles navigation, footer og basisstyles
- `mobile-nav.js`: Mobilnavigation
- `home.js`: Forsidens interaktioner

## Deployment

Sitet er sat op til statisk hosting via GitHub Pages.
